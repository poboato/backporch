3Prove you own the domain
Let's Encrypt fetches a proof file straight from this server — Backporch answers it for you, now and at every renewal. Nothing to create, nothing to copy. The one requirement: forward TCP port 80 on your router to port 80 on this machine. Can't open port 80? Pick a DNS option instead.

That forward does not expose Jellyfin. Backporch holds that port on a listener of its own, which can serve the proof file and nothing else; every other request gets a redirect to HTTPS. Jellyfin's own HTTP port (8096) stays where it is — don't forward it.

Create one here → Create Custom Token, with two permissions: Zone → Zone → Read and Zone → DNS → Edit, limited to this one zone. (Both are needed: the first to find your zone, the second to write the challenge record. The "Edit zone DNS" template grants only the second and will not work on its own.) It stays on this server and is never written to logs.

No token needed. In the next step this page will show you one TXT record to add by hand — with copy buttons — and wait for you. Renewals cannot run unattended in this mode: every renewal needs you back on this page to publish a new record, so the scheduled task will skip it rather than fail silently. 5Turn on HTTPS

Jellyfin now needs to be told to use the certificate. Once, by hand:

  1. Open Dashboard → Networking.
  2. Tick Enable HTTPS.
  3. Paste this into Custom SSL certificate path (leave the password empty):
  4. Tick Require HTTPS. Jellyfin then refuses to serve anything over plain HTTP, on any port, to anyone.
  5. Save, then restart Jellyfin.

To reach the server from outside your home, forward TCP port 443 on your router to this machine's HTTPS port (8920 by default) — then https://your-domain works everywhere. Renewal is automatic from here; a renewed certificate is picked up at the next restart.

Before you open this to the internet, two forwards is the whole list: 443 for Jellyfin over TLS, and 80 for Backporch's proof listener. Anything else — Jellyfin's own 8096 above all — should not be reachable from outside. Then check the rest of the front door: a strong password on every account that can log in, Dashboard → Users pruned of anything you don't recognise, and remote access left off for accounts that don't need it.

Strict Transport Security

After one visit over HTTPS, browsers stop trying HTTP for your domain altogether — so the one plain request that would otherwise be redirected never happens, and nobody can click through a certificate warning.
